# ✍️ دوّنلي (Dawenli)

**نظام لإدارة حياتك بالذكاء الاصطناعي.** تطبيق **PWA** بتثبّته على موبايلك (أو تفتحه من المتصفح)، بتكلّمه **بصوتك** أو بالكتابة عن يومك، وفيه **Agent** حقيقي (tool calling + ذاكرة محادثة) بيفهم كلامك وبيستخرج منه تلقائيًا:

- 💰 **الفلوس** — صرفت كام وفي إيه (بالبنود: أكل، مواصلات، فواتير...) ودخلك.
- 🩺 **الصحة والنفسية** — أعراض، أدوية، تمارين، نوم، أكل، وحالتك النفسية — وتقرير شامل واحد من كل كلامك.
- 🎯 **الأهداف والعادات** — بيعرف أهدافك ويسجّل تقدّمك فيها، وبيتعلّم عاداتك لوحده.
- 📅 **المهام** — «عندي ميتنج بكرة الساعة ٥» → بتتحط في التقويم وبيفكّرك في معادها.

ولو كلامك مش واضح (مبلغ ناقص، معاد مش محدد) **بيسألك سؤال توضيحي ويكمّل التسجيل لما ترد** — عنده ذاكرة.

وبيبادر: **check-in يومي** بيشوف إيه الناقص في يومك (مصاريف؟ عادات؟ يومياتك؟) ويسألك عليه بالتحديد، وتأمّل أسبوعي — كله بيوصلك **إشعارات Web Push** على الموبايل.

**Multi-user:** كل مستخدم له حسابه وبياناته. التسجيل الذاتي مقفول — **الأدمن هو اللي بيفتح الحسابات** من الداشبورد.

## التشغيل محليًا

1. **نصّب الحزم:**
   ```bash
   npm install
   ```

2. **جهّز `.env`:**
   ```bash
   cp .env.example .env
   ```
   املا `OPENAI_API_KEY` وغيّر `DASHBOARD_PASSWORD`.

3. **مفاتيح الإشعارات (اختياري):** لو عايز إشعارات Web Push، ولّد مفاتيح VAPID وحطّها في
   `VAPID_PUBLIC_KEY` و `VAPID_PRIVATE_KEY` و `VAPID_SUBJECT`:
   ```bash
   npx web-push generate-vapid-keys
   ```
   لو سيبتها فاضية، الإشعارات بتتعطّل بهدوء والباقي بيشتغل عادي.

4. **شغّل:**
   ```bash
   npm start
   ```

5. **افتح** `http://localhost:3000`
   - **الأدمن:** `/admin` بكلمة السر `DASHBOARD_PASSWORD` — ومن هناك بتعمل حسابات المستخدمين.
   - **المستخدم:** بيدخل بالحساب اللي الأدمن عمله له.
   - **للتثبيت كتطبيق:** من المتصفح اختر «إضافة إلى الشاشة الرئيسية».

## الاستخدام

- ابعت **voice** أو نص من التطبيق ← الـ agent بيستخرج كل حاجة ويرد عليك + رسالة «اتسجّلت ✅» بالتفاصيل.
- اسأله عن بياناتك: «صرفت كام الشهر ده؟» «إيه مهامي بكرة؟» — بيجاوب من الأرقام الحقيقية.
- **التقرير الشامل** (نفسية + صحة + عادات + أهداف + فلوس) من الداشبورد.
- **الـ check-in** بيجيلك إشعار في معاده (`CHECKIN_HOUR`)، والتأمّل الأسبوعي حسب `WEEKLY_DAY` / `WEEKLY_HOUR`.

## لوحة الأدمن

- إنشاء وإدارة حسابات المستخدمين.
- **إعدادات الـAI** — تغيير الموديلات واختبارها من الواجهة من غير ما تلمس `.env`.
- **تكلفة الـAI** — كل نداء بيتسجّل بتكلفته.
- تحديث النسخة من الواجهة.

## النشر على VPS

```bash
git clone <repo> dawenli && cd dawenli
npm install
cp .env.example .env && nano .env   # املا المفاتيح

npm i -g pm2
pm2 start npm --name dawenli -- start
pm2 save && pm2 startup
```

التطبيق **ويب**، فمحتاج يبقى وراه دومين + شهادة SSL (Nginx مثلًا) — الـPWA وإشعارات الـWeb Push
**مش بتشتغل غير على HTTPS**.

## الهيكل

```
src/
  index.js           تشغيل السيرفر + الجدولة
  config.js          متغيّرات البيئة
  db.js              تخزين SQLite (multi-user + مهام + فئات صرف)
  openai.js          تفريغ الصوت + التحليل + التقرير الشامل
  agent.js           🧠 الـ Agent: الأدوات + حلقة tool calling
  report.js          تجميع بيانات التقرير الشامل
  server.js          API + جلسات + لوحة الأدمن
  push.js            إشعارات Web Push (VAPID)
  scheduler.js       الـ check-in اليومي والتأمّل الأسبوعي
  updater.js         تحديث النسخة من لوحة الأدمن
public/              واجهة الـPWA (RTL): تقويم، body map، مزاج، بنود صرف
scripts/
  backup-db.js       باك أب لقاعدة البيانات
  reset-password.js  إعادة تعيين كلمة سر مستخدم
data/                قاعدة البيانات (SQLite)
```

## الموديلات والتكلفة (تقريبية)

| العملية | الموديل الافتراضي | ملاحظات |
|---|---|---|
| تفريغ الصوت | `gpt-4o-transcribe` | أدق بوضوح في العربي من whisper-1 (~$0.006/دقيقة) |
| الـ Agent | `gpt-4o` | tool calling موثوق — تقدر تنزل لـ gpt-4o-mini لو عايز توفّر |
| التحليل والتقارير | `gpt-4o` | حسب عدد المرّات |

كل نداء بيتسجّل بتكلفته في تاب «تكلفة الـAI» في لوحة الأدمن.
