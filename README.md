# ✍️ دوّنلي (Dawenli)

مساعد يوميات شخصي. بتبعت **voice** على تليجرام عن يومك، وهو بيفرّغه، بينظّمه كتدوينة (تاريخ + مزاج + ملخص + وسوم)، بيحفظه، وبيعرضه في داشبورد بسيط. وتقدر تطلب منه يحلّل أيامك.

النسخة دي **لمستخدم واحد** (انت) وبتشتغل على VPS بـ Node + SQLite + OpenAI.

---

## التشغيل محليًا

1. **نصّب الحزم:**
   ```bash
   npm install
   ```

2. **اعمل البوت:** كلّم [@BotFather](https://t.me/BotFather) على تليجرام، `/newbot`، وخُد التوكن.

3. **جهّز `.env`:**
   ```bash
   cp .env.example .env
   ```
   املا `TELEGRAM_BOT_TOKEN` و `OPENAI_API_KEY` وغيّر `DASHBOARD_PASSWORD`.

4. **شغّل:**
   ```bash
   npm start
   ```

5. **اقفل البوت عليك:** أول ما تكلّم البوت، هيرد عليك بالـ `chat_id` بتاعك. حطّه في `ALLOWED_CHAT_ID` في `.env` وأعد التشغيل — كده محدش غيرك يقدر يستخدمه.

6. **الداشبورد:** افتح `http://localhost:3000` (اسم المستخدم أي حاجة، الباسورد = `DASHBOARD_PASSWORD`).

---

## الاستخدام

- ابعت **voice** للبوت ← بيرد بتأكيد التدوينة.
- `/analyze` ← تحليل آخر ٧ أيام. `/analyze 30` ← آخر ٣٠ يوم.
- الداشبورد ← كل اليوميات + زرار "حلّلي أيامي".

## ⚠️ سير العمل الإلزامي — git هو نقطة الاتصال الوحيدة

**ممنوع تعدّل على السيرفر مباشرة.** أي تعديل بيتعمل على جهازك المحلي، يترفع على git، وبعدين السيرفر بيسحبه. كده الكود متزامن دايمًا بين الجهاز المحلي + GitHub + السيرفر، ومفيش شغل بيضيع.

**الترتيب الصحيح لأي تحديث:**

```bash
# 1) على جهازك المحلي — عدّل، ثم:
git add -A
git commit -m "وصف التغيير"
git push origin main

# 2) على السيرفر — اسحب وطبّق:
ssh root@<server>
cd /root/dawenli
git pull origin main          # السحب من GitHub (نقطة الاتصال)
npm install                   # لو فيه حزم جديدة
pm2 restart dawenli           # إعادة تشغيل البوت بالتحديث
```

> **القاعدة:** السيرفر **بيستقبل** بس (`git pull`) — مابيدفعش (`git push`). كل تغيير مصدره الجهاز المحلي → GitHub → السيرفر.

السيرفر مربوط بـ GitHub عن طريق **Deploy Key** (قراءة فقط) على `/root/.ssh/dawenli_deploy`، والـ remote بصيغة SSH (`git@github.com:...`).

## النشر الأولي على VPS (مرة واحدة)

```bash
# على السيرفر (Ubuntu مثلاً)
git clone git@github.com:mostfamohamedrgab/dawenli.git dawenli && cd dawenli
npm install
cp .env.example .env && nano .env   # املا المفاتيح

# شغّله دايم بـ pm2
npm i -g pm2
pm2 start src/index.js --name dawenli
pm2 save && pm2 startup
```

البوت بيشتغل بـ **polling**، يعني مش محتاج دومين ولا HTTPS ولا فتح بورت — بيتواصل مع تليجرام من جوّه.

للوصول للداشبورد من برّه: افتح البورت (`PORT`) في الـ firewall، أو الأفضل حُطّه ورا Nginx + شهادة SSL.

## الهيكل

```
src/
  index.js    تشغيل البوت + السيرفر
  config.js   متغيّرات البيئة
  db.js       تخزين SQLite
  openai.js   تفريغ الصوت + التصنيف + التحليل
  bot.js      بوت تليجرام
  server.js   API + الداشبورد
public/       واجهة الداشبورد (RTL)
data/         قاعدة البيانات (SQLite)
```

## التكلفة (تقريبية، OpenAI)
- تفريغ Whisper: ~$0.006/دقيقة صوت
- تصنيف (gpt-4o-mini): جنيهات قليلة شهريًا للاستخدام الشخصي
- تحليل (gpt-4o): حسب عدد المرّات

## المحاور المدعومة دلوقتي
البوت بيستخرج من الصوت/النص تلقائيًا:
- 📝 **يوميات** (تاريخ + مزاج + ملخص + وسوم)
- 🎯 **أهداف** برقم وتتبّع تقدّم
- 🏥 **صحة** (تمرين/دواء/أكل/عرض/نوم) + **متابعة حالة** وتوليد **تقرير للطبيب**
- 🍽️ **وجبات** و 🔁 **عادات** (بتعملها / بتبطّلها)
- 💰 **ماليات** (دخل/مصروف)
- 📊 **تتبّع تكلفة OpenAI** لكل نداء
