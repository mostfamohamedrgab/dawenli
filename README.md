# ✍️ دوّنلي (Dawenli) — v2 Agent

منصة تدوين ذكية. بتبعت **voice** أو نص على تليجرام عن يومك، وفيه **Agent** حقيقي (tool calling + ذاكرة محادثة) بيفهم كلامك وبيستخرج منه تلقائيًا:

- 💰 **الفلوس** — صرفت كام وفي إيه (بالبنود: أكل، مواصلات، فواتير...) ودخلك.
- 🩺 **الصحة والنفسية** — أعراض، أدوية، تمارين، نوم، أكل، وحالتك النفسية — وتقرير شامل واحد من كل كلامك.
- 🎯 **الأهداف والعادات** — بيعرف أهدافك ويسجّل تقدّمك فيها، وبيعلّم عاداتك لوحده.
- 📅 **المهام** — «عندي ميتنج بكرة الساعة ٥» → بتتحط في التقويم وبيفكّرك في معادها.

ولو كلامك مش واضح (مبلغ ناقص، معاد مش محدد) **بيسألك سؤال توضيحي ويكمّل التسجيل لما ترد** — عنده ذاكرة.

وبيبادر: **check-in يومي** بيشوف إيه الناقص في يومك (مصاريف؟ عادات؟ يومياتك؟) ويسألك عليه بالتحديد، وتأمّل أسبوعي.

Multi-user جاهز: كل مستخدم تليجرام له حسابه وبياناته، ودخول الداشبورد بكود من البوت (`/code`).

---

## التشغيل محليًا

1. **نصّب الحزم:**
   ```bash
   npm install
   ```

2. **اعمل البوت:** كلّم [@BotFather](https://t.me/BotFather) على تليجرام، `/newbot`، وخُد التوكن.

3. **جهّز `.env`:**
   ```bash
   cp .env.example .env
   ```
   املا `TELEGRAM_BOT_TOKEN` و `OPENAI_API_KEY` وغيّر `DASHBOARD_PASSWORD`.

4. **شغّل:**
   ```bash
   npm start
   ```

5. **الوضع الشخصي أو المنصة:**
   - شخصي: حط الـ `chat_id` بتاعك في `ALLOWED_CHAT_ID` (البوت هيقولهولك أول رسالة) — البوت يرد عليك انت بس.
   - منصة: حط `OPEN_SIGNUP=true` — أي حد يكلم البوت يتعمله حساب تلقائي.

6. **الداشبورد:** افتح `http://localhost:3000`
   - الأدمن: بكلمة السر `DASHBOARD_PASSWORD`.
   - أي مستخدم: يبعت `/code` للبوت وياخد كود دخول صالح ١٠ دقايق.

## الاستخدام

- ابعت **voice** أو نص للبوت ← الـ agent بيستخرج كل حاجة ويرد عليك + رسالة «اتسجّلت ✅» بالتفاصيل.
- اسأله عن بياناتك: «صرفت كام الشهر ده؟» «إيه مهامي بكرة؟» — بيجاوب من الأرقام الحقيقية.
- `/report` ← التقرير الشامل (نفسية + صحة + عادات + أهداف + فلوس) عن آخر ٣٠ يوم. `/report 90` لفترة أطول.
- `/analyze` ← تحليل يومياتك آخر ٧ أيام.
- `/code` ← كود دخول للداشبورد.
- `/checkin` ← يسألك عن يومك دلوقتي بدل ما يستنى المعاد.

## النشر على VPS

```bash
git clone <repo> dawenli && cd dawenli
npm install
cp .env.example .env && nano .env   # املا المفاتيح

npm i -g pm2
pm2 start npm --name dawenli -- start
pm2 save && pm2 startup
```

البوت بيشتغل بـ **polling**، يعني مش محتاج دومين ولا HTTPS ولا فتح بورت.

للوصول للداشبورد من برّه: افتح البورت (`PORT`) في الـ firewall، أو الأفضل حُطّه ورا Nginx + شهادة SSL.

**الترقية من النسخة القديمة:** الميجريشن تلقائي أول تشغيل (جداول users/tasks بتتعمل، والبيانات القديمة بتتربط بصاحب `ALLOWED_CHAT_ID`). راجع `.env` وضيف المتغيّرات الجديدة من `.env.example`.

## الهيكل

```
src/
  index.js    تشغيل البوت + السيرفر
  config.js   متغيّرات البيئة
  db.js       تخزين SQLite (multi-user + مهام + فئات صرف)
  openai.js   تفريغ الصوت + التحليل + التقرير الشامل
  agent.js    🧠 الـ Agent: الأدوات + حلقة tool calling + الـ check-in اليومي
  report.js   تجميع بيانات التقرير الشامل
  bot.js      بوت تليجرام + التذكيرات والمبادرة
  server.js   API + جلسات + أكواد دخول
public/       واجهة الداشبورد (RTL): تقويم، body map، مزاج، بنود صرف
data/         قاعدة البيانات (SQLite)
```
